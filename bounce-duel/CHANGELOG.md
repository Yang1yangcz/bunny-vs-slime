# 变更记录

## v2.0 — 2026-11-19

实时演算页的视觉重做版。目标：把画面拉回视频版那套「蓝底 + 深色描边 + 十字血条」的卡通风格，并补上技能素材与更强的特效。

### 视觉
- 标题移到画框外，还原「兔子 vs 史莱姆」的排版
- 画框加粗到 7px，配硬投影；页面底色改浅蓝渐变
- 血条从横条改回**十字血条**，填充改为**红色血线**，数值压在十字中心
- 左右两侧新增技能 HUD：每个技能带图标、状态、剩余 CD 和进度条
- 技能图标为内联 SVG（锤子 / 冰山 / 光环 / 时钟），与画面同一套描边风格
- 角色立绘放大 ~8%，更接近参考图比例

### 机制
- 冰岛冲击：背景替换为极光雪原照片（推近 + 下雪 + 暗角），**持续 3.4 秒后关闭**
- 冰岛冲击期间：**锁血 2 秒** + **双方冰冻 3 秒**（面对面停止运动，身上结冰壳）
- 站在道德制高点：改为**免疫全部伤害**，加了光柱、光环、粒子
- 历史的回眸：加了倒流环 + 时光碎片回吸特效，并配倒带音效 + 钟声
- **对轴**：兔子血量掉进 42% 后，史莱姆会留技能不自动放；大招引爆瞬间按 `counterChance`（45%）判定，成功则完全免疫并打出「对轴成功」横幅

### 数值
- 全部伤害改为**按最大生命 / 攻击力百分比**表达，写在文件顶部 `CFG` 并带注释
- 冰岛冲击 30% 最大生命、单球 18%、锤击 = 70% 攻击 + 1% 当前生命
- 页面新增「参数」面板，展开即可看到当前生效的全部数值

### 平衡实测
8 局一轮headless 跑：兔子 5 : 3 史莱姆，平均 25.2 秒。
