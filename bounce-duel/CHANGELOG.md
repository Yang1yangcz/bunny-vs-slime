### 撞击计数：累计 + 递增门槛

- `duck.hits` 改成**累计数，只增不减**，每撞一下 +1；状态条与头顶标签同时显示「累计 N 击」
- 本轮进度单独记在 `duck.roundHits`，门槛按轮次递增：
  **第 1 轮 20 次 → 第 2 轮 22 次 → 第 3 轮 24 次…**（`duck.hitsPerStep = 2`）
- 所以总阈值是 20 / 42 / 66 / 92…，平均一局（约 46 次撞击）大多只结算一次，偶尔两次
- 飘字从「撞击 n/20」改成「撞击 5/22」，满一轮显示「满 22 次！」

### 摇摆鸭手感：更 Q 弹、摇得更猛

  被压扁 → 拉长 → 回正，约 0.4 秒一个来回；再叠一层 6.4Hz 的果冻抖动
- 旋转幅度 0.07 → **0.15 rad**、频率更快；游走时的左右摆动 150 → **250**、频率 2.1 → 2.9
- 碰撞反馈补齐：被撞 / 被打都会震屏（0.12，锤子 0.35），配原有的击飞 + 冲击环 + 「嘎」

## v3.0 — 2026-11-28

**新角色：摇摆鸭（中立单位）** + 一套增益结算玩法。兔子 / 史莱姆的技能没有重做，只做了数值微调。

### 新增：摇摆鸭

| 项 | 说明 |
|---|---|
| 出场 | 一开场就在场上，**半透明**（alpha 0.72），既不属于兔子也不属于史莱姆 |
| 可交互 | 会被角色**撞动**（物理互推，鸭子更轻），也会被**锤子**和**史莱姆的球**打到 |
| 自动走位 | 缓缓追向两名角色的中点并左右摇摆，保证它总在交火线上挨打 |
| 计数 | 每挨一次撞击计数 +1（同一角色 0.34s 内只算一次），头顶实时显示 `中立 n / 20` |
| 结算 | **第 20 次撞击者的「对手」**获得增益，同时清空上一次增益；第 40、60… 次同理，直到分出胜负 |
| 视觉 | 加入阵营后不透明度拉满，脚下/身上带对应阵营色的光环，角色卡片顶部出现「鸭之祝福」 |

> 「撞击者的对手」是刻意的反向设计：**谁打鸭子，谁就是在给对面送增益**。
> 所以场上真正的最优解是「别撞它」，但鸭子的走位会自动往交火线钻。

## v2.8 — 2026-11-19

冰岛冲击从「一次性 3000」改成「持续时间内分段结算」，总伤害不变。

### 机制
- `ult.ticks: 6` / `ult.tickGap: 0.5`：冰冻的 3 秒里每 0.5 秒结算一次
- 单段 = `ceil(总伤害 / 段数)` = **500**（原先是 3000 一次性打出）
- 起跳点 `+0.55s`（冰环落地的瞬间），最后一跳在 `+3.05s`，正好覆盖冰冻期
- 每段单独弹伤害数字、冰环、6 片碎冰；眩晕只在第一段施加
- 对轴成功时整段序列不排程（完全免疫仍然是完全免疫）
- 中途打死史莱姆时，剩余段数因 `over` 守卫直接作废

### 平衡
总伤害仍是 3000（30% 生命），48 局实测 **兔子 22 : 史莱姆 26（46%）**，平均 27.5 秒。
改动前后在统计误差内一致，没有破坏 v2.7 的平衡点。

### 观感
单次数字从 3000 降到 500，配合每跳的冰环/碎冰，读起来像「持续受击」而不是一次爆发。

### 数值
- 历史的回眸 CD：26s → **15s**，停手仍为 10s
- 站在道德制高点 CD：22s → **30s**，浮空仍为 5s

  （CD 与停手时间变化后史莱姆输出大降，靠这两项补回来）

### 释放逻辑（重点）
「就绪即放」会让史莱姆放着 5 秒免疫去挡一发普通锤子，或者空放回溯；但一直留着又等于没有技能。改成条件判断 + 到点强制：

**站在道德制高点**
- 兔子血量 ≤ 55% → **留招**，专门等冰岛冲击对轴
- 兔子正在挥锤且距离 ≤ 340 → 起飞硬吃（用掉不亏）
- 自身血量 ≤ 45% → 起飞保命
- 就绪后最多留 **20s**，到点必放
- HUD 上会显示「留招 x s」

**历史的回眸**
- 最近 10s 承伤 ≥ 12% 最大生命才放（放完要停手 10s，乱放等于自废武功）
- 就绪后留满 20s，只要承伤 ≥ 3% 就保底放一次（不会一直不放）
