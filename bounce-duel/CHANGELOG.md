# 变更记录

## v2.7 — 2026-11-19

平衡调整：吸血改为按实际伤害结算，史莱姆基础生命上调。

### 吸血
- 旧：`lifestealAtk 0.10` × 基础攻击 = 固定 300（不看实际打了多少）
- 新：`lifestealRatio 0.10`，`Math.ceil(实际伤害 × 10%)` —— **向上取整**，打多少回多少
- 单球 2550 伤害 → 每次回 255（原来是 300）；被免疫/锁血时伤害为 0，也就不回血
- 详细面板显示为「10% 伤害 · 约 255 / 次」

### 基础数值
| 项目 | 旧 | 新 |
|---|---|---|
| 兔子 maxHp / atk | 10000 / 3000 | 不变 |
| 史莱姆 maxHp | 12500 | **13500**（比兔子高 35%） |
| 史莱姆 atk | 3000 | 不变 |

基础攻击没动：所有伤害都是 `atk × 百分比`，改 atk 等于把双方所有招式等比缩放，
对胜负几乎没有影响，真正决定胜负的是「基础生命」这个池子。

### 实测（每档 24 局，同一套种子）
| 史莱姆 maxHp | 兔子胜率 |
|---|---|
| 13000 | 17:7（71%） |
| **13500** | **11:13 / 16:8 / 14:10 → 累计 41:31（57%）** |
| 14000 | 18:30（37.5%，48 局） |

最终 13500：72 局 41:31，平均 28.4 秒，每局稳定 3 次冰岛冲击。

## v2.5 — 2026-11-19

冰岛冲击改为「全局 3 次 + 释放回血」，伤害公式统一成「基础攻击 × 百分比」。

### 机制
- **冰岛冲击全局 3 次**（`ult.uses`）：每掉到 20% 血触发一次，三次用完不再锁血、可被击杀
- **释放瞬间回血**（`ult.healRatio` 0.30）：回复「此前累计造成的伤害」的 30%，
  实测第一次约 600~2500、第三次约 3000+；带绿色 +N、三重绿环、三音上行音效
- HUD 大招卡显示剩余次数（待触发 3/3 → 已用尽 0/3），详细面板新增
  「大招次数 / 下次回血 / 累计回血」

### 伤害模型统一
- 全场只有 `atk`（基础攻击）是绝对数值，所有伤害 = `atk × 百分比`
- 锤击 0.70×3000 = 2100（≈21% 生命），去掉原来的「1% 当前生命」项
- 冰岛冲击 1.00×3000 = 3000（≈30%），单球 0.85×3000 = 2550（≈25.5%）
- 吸血从「3% 最大生命」改为 `lifestealAtk` 0.10×3000 = 300（同为百分比表达）

### 史莱姆数值重调（为吃下 3 次大招）
| 项目 | 旧 | 新 |
|---|---|---|
| maxHp | 10000 | **12500** |
| spit.period | 4.7s | **2.6s** |
| spit.dmgAtkRatio | 0.70 | **0.85** |

### 修掉的 bug
- **锁血线被同一帧打穿**：兔子血量正好停在 20% 线上时，同一帧的第二次伤害仍能把它打死，
  导致「大招 0 次就阵亡」。改为「已压线则本帧免伤，等 castIce 触发」
- **重开不读新参数**：`reset()` 只把 hp 复位到旧的 maxHp，改 CFG 后点重新开局不生效；
  现在重开会重新读取 `cfg.maxHp / cfg.atk`
- 横幅加胶囊底框，压在极光照片/冰冻特效上也读得清（原来白字会被角色盖住）

### 平衡
56 局实测 **兔子 28 : 史莱姆 28**（50%），平均 27.5 秒，每局稳定打满 3 次冰岛冲击。
调参过程：10000 血 → 兔子 8:0 全胜；14000 血 → 史莱姆 16:8；12500 血落在中间。

### 调试
- `__sim.pause() / resume()` 暂停实时循环，配合 `__sim.advance(秒)` 手动推进
- `__CFG.slime.spit.period = 3` 控制台实时改参数，点「重新开局」生效
- `_tune.py`：无头跑 N 局统计胜率/时长/大招次数的测平衡脚本

## v2.1 — 2026-11-19

技能 CD 调整 + 释放 AI 重做（不再「CD 好了就放」）。

### 数值
- 历史的回眸 CD：26s → **15s**，停手仍为 10s
- 站在道德制高点 CD：22s → **30s**，浮空仍为 5s
- 单球伤害 18% → **21%** 最大生命，喷吐周期 5.0s → **4.7s**
  （CD 与停手时间变化后史莱姆输出大降，靠这两项补回来）

### 释放逻辑（重点）
「就绪即放」会让史莱姆放着 5 秒免疫去挡一发普通锤子，或者空放回溯；但一直留着又等于没有技能。改成条件判断 + 到点强制：

**站在道德制高点**
- 兔子血量 ≤ 55% → **留招**，专门等冰岛冲击对轴
- 兔子正在挥锤且距离 ≤ 340 → 起飞硬吃（用掉不亏）
- 自身血量 ≤ 45% → 起飞保命
- 就绪后最多留 **20s**，到点必放
- HUD 上会显示「留招 x s」

**历史的回眸**
- 最近 10s 承伤 ≥ 12% 最大生命才放（放完要停手 10s，乱放等于自废武功）
- 就绪后留满 20s，只要承伤 ≥ 3% 就保底放一次（不会一直不放）

### 平衡
每轮 12 局 headless 实测：兔子 7 : 5 史莱姆，平均 26.3 秒。
（调参过程中出现过 9:3 与 4:8 两端，最终这组最接近五五开）
